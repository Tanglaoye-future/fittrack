## 💡 关键决策记录

### 为什么选择这些技术？

1. **Next.js + React**
   - 决策：前端框架
   - 原因：全栈能力、SSR 性能优、生态完整
   - 替代方案：Vue 3、Svelte（考虑但最终未选）

2. **NestJS + TypeScript**
   - 决策：后端框架
   - 原因：企业级、模块化、大规模应用成熟
   - 替代方案：Express、Fastify（不够企业级）

3. **Prisma ORM**
   - 决策：数据库映射
   - 原因：类型安全、自动迁移、开发体验好
   - 替代方案：TypeORM、Sequelize（功能足够但不如现代）

4. **PostgreSQL**
   - 决策：主数据库
   - 原因：可靠性高、功能完整、适合复杂查询
   - 替代方案：MySQL（功能不如完整）
